# Online Quiz System

A simple and interactive Online Quiz System developed using HTML, CSS, JavaScript, Python, and Flask.

## Features

- Multiple-choice quiz questions
- 60-second countdown timer
- Automatic score calculation
- Percentage calculation
- Result and performance feedback
- Try Again option
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Jinja2
